# Security

- Credentials remain outside Git and images. Only `pipeline-worker` and the
  opt-in infrastructure tester mount
  `/opt/course-transcript/secrets/gcp-sa.json` at
  `/run/secrets/gcp-sa.json:ro`.
- API, preflight worker, and pipeline worker mount the host rclone config
  read-only; its content must never be printed or returned to browsers.
- Source paths must remain below `gdrive:` and pass extension/traversal checks.
  rclone is invoked with argument arrays, never a browser-built shell string.
- Production mutations require Cloudflare Access identity headers and exact
  Origin. Only the loopback frontend port is published; Cloudflare Tunnel is
  the public entry.
- GCS stays private. Drive upload, public links, IAM, firewall, DNS, Billing,
  Cloudflare routes/policies, and `main` merge require explicit authorization.
- Raw Drive media and provider responses are immutable evidence. Derived
  artifacts may be regenerated by an explicitly requested retry.

Run `rg -n "gemini-2\\.5|BEGIN PRIVATE KEY|eyJhI" .` and inspect only matching
file paths before each release. Never print secret-file content during a scan.
